### แผนการจัดวางหน้าเว็บ

## 1. ตารางแผนการจัดวางส่วนต่าง ๆ ของหน้าเว็บ

| ส่วนหน้า | จอกว้าง 1280 × 800 | จอแคบ 390 × 844 |
| :--- | :--- | :--- |
| **ชื่อร้านและเมนู** | อยู่แนวเดียวกันเมื่อมีพื้นที่พอ | ขึ้นแถวใหม่เมื่อพื้นที่ไม่พอ |
| **การ์ดสินค้า** | สมุดและปากกาวางข้างกัน | สมุดอยู่เหนือปากกา |
| **Form** | ช่องกรอกและปุ่มจัดตามพื้นที่ | ช่องกรอกและปุ่มเรียงลงมา |

## 2. เครื่องมือและเหตุผล

* **ส่วน header ใช้ Flexbox:** เพื่อให้ชื่อร้านและเมนูเรียงแนวเดียวกัน และขึ้นแถวใหม่ได้เมื่อพื้นที่ไม่พอ
* **รายการสินค้า ใช้ Grid:** เพื่อกำหนดจำนวนคอลัมน์ให้การ์ดสินค้าวางข้างกันบนจอกว้าง และเรียงลงมาเป็น 1 คอลัมน์บนจอแคบ
* **Form ใช้ Flexbox:** เพื่อจัดเรียงช่องกรอกข้อมูลและปุ่มกดให้เป็นระเบียบ และปรับขนาดตามพื้นที่หน้าจอได้ง่าย

## 3. ลำดับ Tab

1. สินค้า
2. ตระกร้า
3. ปุ่มเลือกสินค้าชิ้นที่ 1 (สมุด)
4. ปุ่มเลือกสินค้าชิ้นที่ 2 (ปากกา)
5. ช่องเลือกสินค้า / กรอกข้อมูลใน Form
6. ปุ่มส่งข้อมูลใน Form
7. footer

## 4. การจัดหน้าเมื่อจอแคบ (390 × 844)

* เมนูบนส่วนหัวขึ้นแถวใหม่ไม่ล้นจอ
* การ์ดสินค้าเรียงลงมาในแนวตั้งทีละใบ (สมุดอยู่เหนือปากกา)
* ช่องกรอกข้อมูลและปุ่มใน Form ขยายเต็มความกว้างและเรียงต่อกันลงมา
